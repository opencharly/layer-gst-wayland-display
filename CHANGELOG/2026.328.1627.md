# 2026.328.1627 — chore(pin): build the element at v2026.328.1511, which reports dropped navigation on the bus

## Summary

Pins `gst-wayland-display` at tag **`v2026.328.1511`** (`b38bbeb`), the merge of opencharly/gst-wayland-display#19, which posts an unparseable navigation event on the **GStreamer bus** instead of only to a discarded stderr.

That is an observability fix, and it is the one that makes the current hunt tractable: this element's service captures stdout only (`spec#432`: a service cannot declare a stderr log), so a navigation event the element DROPS looked identical, from outside, to one it never received. Two rounds of opencharly/charly-streamer#23 were spent on exactly that confusion.

The archive URL, the extraction directory and the `BUILD_COMMIT` assertion move together to one value; `gwd-build-commit` asserts the exact SHA.
